Uncategorized income, expenses and 'Ask My Accountant'

Why it happens

Transactions were added from the bank feed without a real category, so they land in Uncategorized Income, Uncategorized Expense or Ask My Accountant. Your profit and loss and your tax return are wrong until they're sorted.

How to fix it

  1. Run a Profit and Loss report and click the uncategorized lines to see the transactions
  2. Recategorize each one to the correct account
  3. Set up bank rules for repeating vendors so the same transaction is categorized automatically next time
  4. Do this monthly rather than at year end

When to get help

If there are hundreds of them, bulk cleanup with the Reclassify tool in QuickBooks Online Accountant is much faster than one at a time.
