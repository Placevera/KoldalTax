# koldaltax.com

Static website for Koldal Tax & Advisory, hosted on GitHub Pages. The contact form and newsletter signup
go to a Supabase edge function that saves each submission and emails it to alek@koldaltax.com via Resend.

## One-time setup

### 1. Supabase
1. Run `supabase/migrations/20261014000000_submissions.sql` in the Supabase SQL editor (creates the `submissions` table).
2. Deploy the function: `supabase functions deploy contact --project-ref <your-ref>`
3. Set its secrets:
   `supabase secrets set RESEND_API_KEY=re_... NOTIFY_EMAIL=alek@koldaltax.com FROM_EMAIL="Koldal Tax Website <website@koldaltax.com>"`
4. Put the project URL and anon key into `assets/config.js` (Project Settings > API).

### 2. Resend (sends the notification emails)
1. Create a free account at resend.com and add the domain `koldaltax.com`.
2. Add the DNS records Resend shows you (SPF/DKIM on a `send` subdomain). These do **not** touch your inbox's MX records.
3. Create an API key and use it as `RESEND_API_KEY` above.

### 3. GitHub Pages
Settings > Pages > Deploy from branch `main`, folder `/`. The `CNAME` file sets the custom domain to `www.koldaltax.com`.

### 4. DNS (do this last, then cancel the Squarespace site plan)
At whoever manages the koldaltax.com DNS (Squarespace Domains if the domain was bought there):
- `www` CNAME -> `placevera.github.io` (or the repo owner's `<user>.github.io`)
- apex `@` A records -> 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153
- **Leave every MX, TXT (SPF/DKIM/DMARC) and email-related record exactly as it is**, or incoming mail to alek@koldaltax.com stops.

Keep the domain registration itself when cancelling the Squarespace *website* plan.

## Images
Drop a headshot at `assets/headshot.jpg` (about 760x950) to show it on the About page.

## Editing pages
Pages are generated by `tools/build.py` (text lives there) and `tools/notices.json` (IRS notice guides).
After editing, run `python3 tools/build.py .` from the repo root and commit the result.
